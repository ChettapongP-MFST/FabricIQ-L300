3. KEY DESIGN DECISIONS
----------------------------------------------------------------
- 3 business domains (A=Customer, B=Products, C=Sales&Engagement) → one
  ontology per domain → cross-ontology relationships in Lab 2.
- All amounts in THB; Thai names via faker `th_TH`; Bangkok-flavored branches.
- Streaming delivered as a Fabric notebook (per user request), not a CLI.
- Generated CSVs are git-ignored; only generator scripts + small JSONL
  samples are committed.
- Lab markdowns use [screenshot: ...] placeholders to be filled when
  attendees run the lab.
- L200 repo (https://github.com/ChettapongP-MFST/FabricIQ) is referenced as
  the on-ramp.

4. RESUME ON ANOTHER DEVICE — quick start
----------------------------------------------------------------
# Clone (SSH if you've added your key to GitHub on the new device, otherwise HTTPS+PAT)
git clone git@github.com:ChettapongP-MFST/FabricIQ-L300.git
cd FabricIQ-L300

# (Optional) install gh without sudo on macOS arm64
mkdir -p ~/.local/bin && cd /tmp
curl -L -o gh.zip https://github.com/cli/cli/releases/download/v2.92.0/gh_2.92.0_macOS_arm64.zip
unzip -o gh.zip -d gh-extract
cp gh-extract/gh_2.92.0_macOS_arm64/bin/gh ~/.local/bin/gh
chmod +x ~/.local/bin/gh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
unset GITHUB_TOKEN GH_TOKEN
gh auth login --hostname github.com --git-protocol ssh --skip-ssh-key --web

# Generate the data
cd data/generators
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python generate_batch_data.py            # writes CSVs into ../batch/
python generate_streaming_sample.py      # writes JSONL into ../streaming/

# Start the labs
open ../../labs/lab-01-ontology-from-scratch/README.md
